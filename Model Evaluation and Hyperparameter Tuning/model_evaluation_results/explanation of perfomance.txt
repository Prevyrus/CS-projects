Answering the discussion, I was able to observed the following,
First, the downsampling removes majority-class observations, which creates an even class distribution but also discards potentially useful data.
Second, the upsampling keeps all majority-class observations and duplicates minority-class observations. It can improve minority detection but it could cause increase overfitting.
Third, the test set was not resampled, so all three approaches were evaluated on the same original distribution. 
And fourth, in this run, Original produced the highest macro F1 score (0.991).
